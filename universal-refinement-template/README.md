# Universal Refinement Template

> A 5-step framework for breaking any task into motion. Built for ADHD brains, creator workflows, and anyone who gets stuck at "start."

## What It Is

The Universal Refinement Template is a repeatable system for:
- Naming what you're doing (OBJECT)
- Assessing what you have (STATE)
- Identifying what blocks you (FRICTION)
- Taking the next action (MOTION)
- Learning from execution (REFINEMENT)

## The Template

```markdown
# [OBJECT] — What is the thing?
Name it in one sentence. No scope creep.

# [STATE] — What do I have right now?
Time, energy, tools, mood. Be honest.

# [FRICTION] — What blocks motion?
Perfectionism? Fear? Not knowing the tool? Name the smallest version.

# [MOTION] — What is the next executable action?
Not the plan. The NEXT action. Timebox to 15 minutes.

# [REFINEMENT] — What did I learn?
After execution: what worked? What didn't? Update your system.
```

## How to Use

1. Copy the template
2. Fill it out for ONE task (keep it small)
3. Execute the motion step
4. Refine
5. Repeat
