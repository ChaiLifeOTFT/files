# UNIVERSAL REFINEMENT TEMPLATE — CREATOR EDITION

> *"Chaos into structure. Structure into motion. Motion into output."*

---

## 1. OBJECT
**What is the thing?**

Name it in one sentence. No abstraction. No metaphor.

```
The thing is: ________________________________________________
```

**Who is it for?**

```
For: _________________________________________________________
```

**What does it do?**

```
It: __________________________________________________________
```

## 3. FRICTION
**What blocks motion?**

Be honest. Name the resistance.

```
The block is: ________________________________________________
```

**Is the block real or imagined?**

- [ ] Real (resource, skill, dependency)
- [ ] Imagined (fear, ambiguity, perfectionism)

**What is the smallest version of this block?**

```
The smallest block is: _______________________________________
```

## 4. MOTION
**What is the next executable action?**
