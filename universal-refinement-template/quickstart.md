# QUICKSTART — Universal Refinement Template

> *Get from idea to shipped in 5 steps. Under 15 minutes.*

---

## The Loop

```
OBJECT → STATE → FRICTION → MOTION → REFINEMENT → (repeat)
```

---

## Step 1: OBJECT (2 min)
- Name the thing in one sentence
- Name who it's for
- Name what it does

*If you can't name it in one sentence, it's too big. Cut it in half.*

---

## Step 2: STATE (2 min)
- List assets you already have
- List constraints
- Note time available

*You have more than you think. Write it down.*

---

## Step 3: FRICTION (2 min)
- Name what blocks motion
- Ask: is this real or imagined?
- Find the smallest version of the block

*Most blocks are imagined. The smallest version is usually trivial.*

---

## Step 4: MOTION (5 min)
- Write the next executable action
- Timebox it
- Define "done"

*Not the plan. Not the strategy. The NEXT action.*

---

## Step 5: REFINEMENT (2 min)
- Execute the action
- Note what worked
- Note what didn't
- Set the next OBJECT

*This is where you get smarter. Don't skip it.*

---

## Rules

1. **One artifact per day.** Blog post, product update, email, script, page.
2. **Price between $5–$19.** Small enough to impulse-buy. Big enough to value.
3. **Publish to Gumroad.** Or your platform of choice. But PUBLISH.
4. **Timebox everything.** If it's not done in the timebox, ship what you have.
5. **No zero days.** Even 15 minutes of motion counts.
